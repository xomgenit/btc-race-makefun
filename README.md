A range-trading bot for cbBTC/USDC: it buys when the 1-minute close falls more than 2.5 standard deviations below the mean of the previous 240 closes, and sells at the opposite band (or a 1% stop-loss), trading the range extremes instead of chasing trends that bleed fees on this choppy market.

## Run it

```sh
node main.ts
```
